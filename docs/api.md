# Engine local API

Generated by `uv run clipapp-engine openapi --markdown -o ../docs/api.md`; do not edit by hand.

Start: `clipapp-engine serve --port 0 --token <token>` listens on `127.0.0.1` and prints one
line `{"ready": true, "port": N}` on stdout. Every route needs the `X-ClipApp-Token` header;
media routes and the `/events` WebSocket also accept `?token=`. Without it: 401. Interactive
docs: `http://127.0.0.1:N/docs` (use *Authorize* to set the token).

Errors are `{"detail": "..."}` with 404 (missing row/file), 409 (wrong state), 422 (invalid
input or media).

## WebSocket `/events`

JSON messages:

- `{"type": "job_progress", "id", "progress"}` (at most 5 per second per job)
- `{"type": "job_status", "id", "status", "error", "output_path"}`
- `{"type": "project_updated", "id"}`

Job states: `queued`, `running`, `done`, `failed`, `cancelled`. Kinds: `prepare`, `full`,
`clip`, `transcribe`. Jobs run one at a time; on restart, unfinished ones become `failed` with
error `interrupted`.

## System

- `GET /health`: Report that the engine is up. → 200 `Health`
- `GET /system`: Run ``doctor``: FFmpeg, encoders, GPUs, CUDA, data dir and free disk (takes seconds). → 200 `object`

## Exports

- `GET /exports`: List every job (prepare, exports, transcriptions), newest first. → 200 `list[Job]`
- `POST /exports`: Queue one export or a batch; every target is checked before anything is queued. Body: `ExportRequest | list[ExportRequest]`. → 202 `list[Job]`
- `POST /exports/{job_id}/cancel`: Cancel a queued or running job. → 200 `Job`
- `POST /exports/{job_id}/retry`: Queue a failed or cancelled job again. → 200 `Job`

## Settings

- `GET /settings`: Return the app settings. → 200 `Settings`
- `PUT /settings`: Replace the app settings. Body: `Settings`. → 200 `Settings`

## Projects

- `GET /projects`: List every project, most recently updated first. → 200 `list[Project]`
- `POST /projects`: Probe a recording, create its project and queue its preparation. Body: `ProjectCreate`. → 201 `Project`
- `GET /projects/{project_id}`: Return one project. → 200 `Project`
- `PATCH /projects/{project_id}`: Rename a project or change its tracks; a new mic track rebuilds the prepared files. Body: `ProjectPatch`. → 200 `Project`
- `DELETE /projects/{project_id}`: Delete a project's data and cache (the original video is never touched). → 204
- `POST /projects/{project_id}/relink`: Point a project at its moved recording; the file must have the same fingerprint. Body: `Relink`. → 200 `Project`

## Silence

- `GET /projects/{project_id}/silence`: Return silence settings, ranges and statistics. → 200 `Silence`
- `PUT /projects/{project_id}/silence`: Save the settings and recompute the silences now (keeps unchanged ranges' toggles). Body: `SilenceSettings`. → 200 `Silence`
- `GET /projects/{project_id}/silence/suggest`: Suggest a threshold from the mic track's noise floor. → 200 `ThresholdSuggestion`
- `PATCH /silence-ranges/{range_id}`: Enable or disable one silence. Body: `SilenceRangePatch`. → 200 `SilenceRange`

## Clips

- `GET /projects/{project_id}/clips`: List a project's clips in time order. → 200 `list[Clip]`
- `POST /projects/{project_id}/clips`: Create a clip (15-60 s inside the video). Body: `ClipFields`. → 201 `Clip`
- `GET /clips/{clip_id}`: Return one clip. → 200 `Clip`
- `PATCH /clips/{clip_id}`: Edit a clip; moving its start or end marks its transcript stale. Body: `ClipPatch`. → 200 `Clip`
- `DELETE /clips/{clip_id}`: Delete a clip and its transcript. → 204

## Transcripts

- `GET /clips/{clip_id}/transcript`: Return a clip's transcript. → 200 `TranscriptOut`
- `POST /clips/{clip_id}/transcript`: Queue the transcription of a clip (replaces any previous transcript). → 202 `Job`
- `PUT /clips/{clip_id}/transcript`: Save corrected words (the transcript becomes ``edited`` and no longer stale). Body: `TranscriptEdit`. → 200 `TranscriptOut`

## Styles

- `GET /styles`: List the subtitle styles (factory ones first). → 200 `list[Style]`
- `POST /styles`: Create a custom style. Body: `SubtitleStyle`. → 201 `Style`
- `PATCH /styles/{style_id}`: Edit a style (factory styles too; they only cannot be deleted). Body: `StylePatch`. → 200 `Style`
- `DELETE /styles/{style_id}`: Delete a custom style; clips using it lose their subtitles style. → 204

## Media

- `GET /projects/{project_id}/media/proxy`: Stream the 720p proxy (supports HTTP Range). → 200 `object`
- `GET /projects/{project_id}/media/waveform`: Return the waveform peaks JSON (audiowaveform v2 format). → 200 `object`
- `GET /projects/{project_id}/media/thumbnails`: Return the thumbnail sprite (JPG grid). → 200 `object`
- `GET /projects/{project_id}/media/thumbnails/index`: Return the sprite layout JSON (interval, size, columns, rows, count). → 200 `object`
- `GET /projects/{project_id}/media/tracks/{track}/preview`: Return 5 s of one audio track from the middle of the recording (AAC in M4A, cached). → 200 `object`
